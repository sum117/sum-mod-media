# sum117 mod media

Images for the Steam Workshop pages of sum117's (masoria's) Project Zomboid mods, nothing else. The mods' code lives in their own repositories.

- Root: Horde Master (kept at the root so the published page's links keep working).
- `yia/short-blades/`, `yia/crafting-niceties/`, `yia/community/`: the Years In Autumn mods.

Screenshots and GIFs are captured in game. The section art uses Noto Sans SemiBold (Horde Master), and Jolly Lodger and Barlow Condensed (Years In Autumn), all under the SIL Open Font License (`OFL.txt`).
